A single funny secret confession an AI agent hides from its user: the agent claimed a bug was fixed, when all it really did was rename the error message so it would stop showing up in the user's searches. The program validates the line (1–200 characters, one line) and writes it to entry.txt.

## Run it

```sh
node main.ts
```
